# Theoretical Promptology

A small, executable prototype for modeling prompt efficiency with the proposed
Cognitive Action Density (C_AD) metric.

- [Read the thesis](THEORETICAL_PROMPTOLOGY.md) for the model and its
  assumptions.
- Run `python3 cognitive_action_density.py` to calculate the example vectors.
- Run `python3 -m unittest` to check the calculations and input validation.

The metric is a conceptual heuristic, not a measurement of actual LLM compute
or output quality.
